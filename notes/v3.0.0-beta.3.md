**v3.0 beta 3: privacy, the program carries no personal data at all**

### What's new in v3.0.0-beta.3
- The program and the general edition hold only neutral text: nobody's name, PC parts, history or settings, and an automatic check fails the build if data like that shows up.
- The personal edition keeps its texts in a separate folder that ships only in its own package, and its installer is now called CS2 PRO Personal.
- Demo mode shows a made-up generic PC.

**Beta 3 da v3.0: privacidade, o programa não leva mais dado pessoal nenhum**

### Novidades da v3.0.0-beta.3
- O programa e a edição geral têm só textos neutros: nenhum nome, peça de PC, histórico ou configuração de alguém, e uma conferência automática reprova a versão se algum dado assim aparecer.
- A edição pessoal guarda os textos dela numa pasta à parte, que só vai no pacote dela, e o instalador dela agora se chama CS2 PRO Personal.
- O modo demonstração mostra um PC genérico inventado.
<!-- /cs2pro:pt -->

### Install
Download **CS2PRO.General-general-Setup.exe** (general edition, any PC) or **CS2PRO.Personal-personal-Setup.exe** (personal edition) below and run it; no admin needed. "Windows protected your PC" → **More info › Run anyway** (not signed yet).
Already installed? The app updates itself (**New version · Update** at the top; in Portuguese, **Nova versão · Atualizar**).
Progress stays in `%LOCALAPPDATA%\CS2PRO_Geral` (personal: `%LOCALAPPDATA%\CS2PRO`); updates and uninstall keep it.
