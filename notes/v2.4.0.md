**Automatic updates: install once and the app updates itself, without losing your progress**

### What's new in v2.4.0
- Automatic updates: install once with the installer (no Extract All, with a Start menu shortcut) and from then on the New version strip shows what changed and updates with one click, downloading only what changed.
- A running test is never cut off without asking: you can update when it ends, now (the test stops) or cancel.
- Your progress stays where it always was, outside the program folder: updating, repairing or uninstalling never touches it, and coming from the zip you pick up where you left off.
- In the three-dot menu: Check for updates automatically (on) and Check for updates now; beta versions only for those who turn them on in the v3 Lab.
- A zip copy doesn't update itself: it shows the link to install with automatic updates once. The zips keep coming out as always.

**Atualização automática: instala uma vez e o painel se atualiza sozinho, sem perder o progresso**

### Novidades da v2.4.0
- Atualização automática: instala uma vez pelo instalador (sem Extrair tudo, com atalho no menu Iniciar) e, daí em diante, a faixa Nova versão mostra o que mudou e atualiza com um clique, baixando só o que mudou.
- Teste rodando nunca é cortado sem perguntar: dá pra atualizar quando ele terminar, agora (o teste para) ou cancelar.
- Teu progresso fica onde sempre esteve, fora da pasta do programa: atualizar, reparar ou desinstalar não mexe nele, e quem vem do zip continua de onde parou.
- No menu de 3 pontinhos: Procurar atualizações sozinho (ligado) e Procurar atualização agora; versão beta só pra quem ligar no Laboratório v3.
- Cópia em zip não se atualiza sozinha: mostra uma vez o link pra instalar com atualização automática. Os zips continuam saindo como sempre.
<!-- /cs2pro:pt -->

### Install
Download **CS2PRO.General-general-Setup.exe** (general edition, any PC) or **CS2PRO.Personal-personal-Setup.exe** (personal edition) below and run it; no admin needed. "Windows protected your PC" → **More info › Run anyway** (not signed yet).
Already installed? The app updates itself (**New version · Update** at the top; in Portuguese, **Nova versão · Atualizar**).
Progress stays in `%LOCALAPPDATA%\CS2PRO_Geral` (personal: `%LOCALAPPDATA%\CS2PRO`); updates and uninstall keep it.
